LIPPS LEARN

Learn the discipline. Practise the reasoning.

LIPPS Learn delivers structured public-health courses that move from explanation to application to assessment. The goal is not to memorise terminology, but to recognise a problem, choose a defensible approach and interpret evidence correctly.

The LIPPS weekly learning cycle

Every week uses the same structure so students know exactly how to study.

01 — ORIENT
Learning outcomes, key question and why the topic matters.

02 — LEARN
Narrative teaching with diagrams, examples and core concepts.

03 — APPLY
A realistic public-health case, worked example or decision problem.

04 — PRACTISE
Objective questions with immediate explanatory feedback.

05 — DEMONSTRATE
A timed weekly quiz that tests recognition, application and interpretation.

Assessment that rewards preparation

LIPPS uses objective questions for weekly checks, but the mastery target is application rather than recall. The current candidate banks contain a mixture of strong applied items, repeated calculation variants and foundation-level concept checks. Before high-stakes institutional use, the mastery pools must be separated from practice items and reviewed against a formal blueprint.

Scenario first

Instead of asking for a definition, questions present a short public-health situation and ask the learner to identify the best interpretation, design, measure or action.

Time-disciplined

Weekly mastery quizzes use a short, transparent time limit that gives a prepared learner enough time to read, reason and answer without rewarding extensive external searching.

Randomised

Questions are sampled from larger topic banks, options can be shuffled, and calculation questions can use parameterised values so learners do not all receive identical tests.

Accessible by design
Copy and paste remain available. LIPPS does not depend on disabling normal browser functions to protect an assessment. Institutions can provide approved extra-time accommodations while retaining the same question blueprint.

Public syllabus. Private learning record.

The public LIPPS website explains each course and keeps the syllabus discoverable. LIPPS Learn, powered by Moodle, handles enrolment, lessons, quizzes, grades and progress.

LIPPS website → Choose a course → LIPPS Learn (Moodle) → Study → Practise → Timed quiz → Progress

This separation keeps LIPPS open and discoverable while giving enrolled learners and universities a proper learning-management environment.

For universities

LIPPS courses are designed so they can be used as supplementary digital courseware rather than replacing the lecturer or the institution’s curriculum.

A university-facing implementation can provide:

  • a 12-week structured course;
  • weekly objective quizzes and reusable question banks;
  • instructor access to grades and completion;
  • cohort-level performance reporting;
  • institution-defined assessment timing and accommodations;
  • links from course lessons into the public LIPPS Methods library and Projects;
  • Moodle/LMS integration options as the institutional product develops.
